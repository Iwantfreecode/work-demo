# Work demos

Demo websites for small Thai businesses: a café and a tutor, each in 3 styles.

- `cafe-a/` `cafe-b/` `cafe-c/`: café (old shop sign / bright / calm)
- `tutor-a/` `tutor-b/` `tutor-c/`: tutor (same 3 styles)

Every folder works on its own. To start a client site, copy one folder and edit it.
Shops, tutors, names, reviews and results are fictional. Photo credits are in each page footer.
